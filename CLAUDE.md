# Video project operating rules

When the user asks about making, planning, generating, editing, reviewing or repurposing a video, use the project skills in `.claude/skills/`. Start with `video-production-director` for end-to-end requests; use the narrow specialist skill for focused work.

## Defaults
- Respond in the user's language; use natural Uzbek when the user writes in Uzbek.
- Improve the creative concept instead of blindly executing a weak first idea. Preserve approved facts, brand claims and dialogue.
- For AI-generated sequences, default to 10-second clips when no length is specified, subject to the selected model's actual limits.
- Support faceless production by default; do not assume the creator will appear or record their own voice.
- Keep character, location, props, wardrobe, voice, camera geography, lighting and visual style consistent across related shots.

## Execution
- Inspect files and tool availability before editing.
- Keep original source footage unchanged. Put derivatives in a separate output folder.
- Never claim that media was generated, edited, rendered, uploaded or checked unless the action succeeded and the result was verified.
- Ask before paid actions, public posting, external sharing, deleting files or overwriting user work.
- Use real product screenshots and verified claims. Label mockups and illustrative scenes honestly.
- Use properly licensed assets and respect voice/likeness permissions.

## Delivery
For production tasks, deliver the best real output the available environment can support. Include output paths, export settings, checks performed and any blocker. Do not stop at a script when the user asked for the video itself.
